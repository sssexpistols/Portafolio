# Base de datos del portafolio

Modelo relacional demostrativo para integrar usuarios, áreas, activos, tickets y mantenimientos.

## Archivos

- `schema.sql`: tablas, claves, restricciones e índices.
- `sample_data.sql`: conjunto mínimo de datos completamente ficticios.
- `queries.sql`: consultas de operación, SLA, inventario y mantenimiento.

## Ejecución

1. Crear una base vacía.
2. Ejecutar `schema.sql`.
3. Ejecutar `sample_data.sql`.
4. Probar las consultas de `queries.sql`.

El modelo utiliza SQL estándar. MySQL, PostgreSQL y SQL Server pueden requerir ajustes menores de tipos o funciones al extenderlo.
